### Project Overview
The Dealerships Review Application is a comprehensive cloud-native web application built for a national car dealership network across the United States. 

The application architecture consists of:
- **Frontend:** React, HTML5, CSS3, and Bootstrap for dynamic dealer listings, review filtering, and user interactions.
- **Backend Server:** Django (Python) providing user management, authentication, proxy APIs, and dynamic templates.
- **Microservices & Database:** Node.js with Express and MongoDB handling dealer records and customer reviews.
- **Sentiment Analysis Microservice:** Natural language sentiment evaluation for customer reviews deployed in cloud runtime.
- **DevOps:** Containerized with Docker and deployed with CI/CD automation.
